# 项目演示材料

## 📊 AI智能数据分析系统 - 演示指南

---

## 一、演示概述

### 项目定位
基于多智能体技术的企业轻量化智能数据分析平台，实现自然语言提问到自动化报告生成的全流程闭环。

### 演示目标
展示系统核心功能，包括数据上传、自然语言分析、异常检测、图表可视化和报告生成。

### 演示时长
约15分钟

---

## 二、演示流程

### 🎬 环节1：系统介绍（2分钟）

**演示要点**:
- 项目背景和价值
- 核心功能概述
- 技术架构简介

**讲解脚本**:
```
大家好，欢迎来到AI智能数据分析系统的演示。

本系统是基于多智能体技术的企业轻量化智能数据分析平台。
它能够让业务人员通过自然语言提问，自动完成数据分析并生成报告。

系统包含三个核心智能体：
1. 数据理解Agent - 理解用户意图
2. 数据分析Agent - 执行分析任务
3. 报告生成Agent - 生成业务报告

让我们开始演示...
```

---

### 🎬 环节2：数据管理（3分钟）

**演示要点**:
- 文件上传
- 数据预览
- 数据源管理

**演示步骤**:
1. 打开"数据管理"页面
2. 上传 `sales_transactions.csv` 文件
3. 展示上传成功后的数据源列表
4. 预览数据内容

**讲解脚本**:
```
首先，让我们上传一份销售交易数据。

我选择sales_transactions.csv文件，这是一份包含10000条记录的销售数据。

可以看到，文件已经成功上传，系统自动识别了字段信息。

我们可以预览数据内容，查看字段类型、数据样本等信息。
```

---

### 🎬 环节3：自然语言分析（4分钟）

**演示要点**:
- 选择数据源
- 输入问题
- 执行分析

**演示步骤**:
1. 切换到"问答分析"页面
2. 选择刚上传的数据源
3. 输入问题："分析销售数据是否存在异常"
4. 点击"开始分析"
5. 展示分析过程

**讲解脚本**:
```
现在让我们进行自然语言分析。

首先选择数据源，然后输入问题。

我输入："分析销售数据是否存在异常"

点击开始分析，系统会自动：
1. 理解用户意图（异常检测）
2. 匹配数据源字段
3. 执行统计分析和异常检测
4. 生成可视化图表
5. 生成分析报告

可以看到分析正在进行中...
```

---

### 🎬 环节4：结果展示（3分钟）

**演示要点**:
- 图表可视化
- 异常检测结果
- 分析报告

**演示步骤**:
1. 展示生成的图表
2. 解释异常检测结果
3. 展示分析报告

**讲解脚本**:
```
分析完成！让我们看看结果。

首先是可视化图表，系统根据分析结果生成了：
- 散点图展示数据关系
- 时间序列图标记异常点
- 异常类型分布图

然后是异常检测结果，系统检测到了60个异常点，包括：
- discount_rate字段的同比异常
- unit_price字段的环比异常
- quantity字段的环比异常

最后是完整的分析报告，包含：
- 分析摘要
- 异常详情
- 统计分析
- 业务建议
```

## 四、FAQ准备

### 常见问题

**Q1: 系统支持哪些数据格式？**
A: 目前支持CSV和Excel格式，后续会扩展更多格式。

**Q2: 如何保证数据安全？**
A: 系统采用本地部署方式，数据存储在本地，不对外传输。

**Q3: 支持哪些大模型？**
A: 目前支持OpenAI和阿里云通义千问，可配置切换。

**Q4: 如何部署到生产环境？**
A: 提供完整的部署文档，支持Docker容器化部署。

**Q5: 是否支持多数据源关联分析？**
A: 当前版本支持单数据源分析，多数据源关联正在规划中。
